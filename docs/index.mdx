# MCP Server Grist

Le serveur MCP Grist permet aux modèles de langage d'interagir avec l'API Grist pour accéder et manipuler des données structurées dans des documents Grist.

## Quand utiliser

Utilisez ce serveur MCP lorsque vous souhaitez :

- Accéder à des données structurées stockées dans Grist
- Créer, modifier ou supprimer des enregistrements dans des tables Grist
- Exécuter des requêtes SQL sur vos données Grist
- Créer des tables, des colonnes et des schémas complets avec relations
- Gérer des documents, espaces de travail et organisations Grist

## Prérequis

- Une clé API Grist valide
- L'URL de l'API Grist (par défaut : `https://docs.getgrist.com/api`)
- Python 3.10 ou supérieur

## Installation

```bash
pip install mcp-server-grist
```

Ou sans installation, avec `uvx mcp-server-grist`.

## Configuration

### Avec Claude Desktop

Ajoutez à votre fichier `claude_desktop_config.json` :

```json
{
  "mcpServers": {
    "grist-mcp": {
      "command": "uvx",
      "args": ["mcp-server-grist"],
      "env": {
        "GRIST_API_KEY": "votre_clé_api_grist",
        "GRIST_API_URL": "https://docs.getgrist.com/api"
      }
    }
  }
}
```

### Démarrage manuel

```bash
export GRIST_API_KEY="votre_clé_api_grist"
export GRIST_API_URL="https://docs.getgrist.com/api"

# Mode stdio (clients MCP locaux)
mcp-server-grist --transport stdio

# Mode HTTP
mcp-server-grist --transport streamable-http --port 8000
```

## Outils disponibles

Le serveur expose 54 outils, regroupés en catégories :

- **Navigation** : organisations, espaces de travail, documents, tables, colonnes, enregistrements
- **Enregistrements** : ajout, modification, suppression
- **Requêtes SQL** : `filter_sql_query` (filtrage simple) et `execute_sql_query` (SELECT libre)
- **Administration** : espaces de travail, documents, tables, colonnes
- **Schéma et relations** : `create_schema`, `validate_schema`, `create_reference_column`, `export_schema`
- **Gestion des accès**, **export** (SQLite, Excel, CSV), **pièces jointes**, **webhooks**

Le détail de chaque outil et de ses paramètres se trouve dans la [référence des outils](./tools-reference.mdx).

## Exemples d'utilisation

### Exécuter une requête SQL

```python
await execute_sql_query(
    doc_id="abcd1234",
    sql_query="SELECT * FROM Tasks WHERE Status = ?",
    parameters=["Completed"]
)
```

### Ajouter des enregistrements

```python
await add_grist_records(
    doc_id="abcd1234",
    table_id="Tasks",
    records=[
        {"Title": "Nouvelle tâche", "Status": "À faire"},
        {"Title": "Autre tâche", "Status": "En cours"}
    ]
)
```

### Créer deux tables reliées

```python
await create_schema(
    doc_id="abcd1234",
    schema={
        "tables": {
            "Projets": {"columns": {"nom": "Text"}},
            "Taches": {"columns": {
                "titre": "Text",
                "projet": {"type": "Ref", "target": "Projets", "visible": "nom", "reverse": "taches"}
            }}
        }
    }
)
```

## Dépannage

1. Vérifiez que votre clé API Grist est valide
2. Assurez-vous que l'URL de l'API est correcte (`GRIST_API_URL`)
3. Consultez les logs du serveur (option `--debug` pour plus de détails)
