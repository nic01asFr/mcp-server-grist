Serveur MCP pour Grist

Un assistant IA qui travaille dans vos documents Grist

mcp-server-grist relie un assistant IA (Claude, ou tout client compatible MCP) à l'API Grist. Vous lui demandez en langage courant de chercher une information, de compléter une table ou de créer une base complète avec ses relations : il le fait dans vos documents, avec vos droits.

Installer en une minute

Il vous faut une clé API Grist (dans Grist : Paramètres du profil → API) et l'adresse de l'API de votre instance. Le serveur est lancé par uvx, sans installation préalable.

Claude Desktop

Ajoutez ceci au fichier claude_desktop_config.json, puis redémarrez Claude.

{
  "mcpServers": {
    "grist": {
      "command": "uvx",
      "args": ["mcp-server-grist"],
      "env": {
        "GRIST_API_KEY": "votre_clé_api",
        "GRIST_API_URL": "https://grist.numerique.gouv.fr/api"
      }
    }
  }
}

Claude Code

Une commande dans le terminal.

claude mcp add grist \
  -e GRIST_API_KEY=votre_clé_api \
  -e GRIST_API_URL=https://grist.numerique.gouv.fr/api \
  -- uvx mcp-server-grist

Autre client MCP

Commande uvx, argument mcp-server-grist, et les deux variables GRIST_API_KEY et GRIST_API_URL. Le serveur parle aussi HTTP (option --transport streamable-http).

uvx mcp-server-grist

Docker

Pour un déploiement isolé.

docker run -i --rm \
  -e GRIST_API_KEY=votre_clé_api \
  -e GRIST_API_URL=https://grist.numerique.gouv.fr/api \
  mcp/grist-mcp-server

Ce que vous pouvez lui demander

  • « Dans le document Suivi des chantiers, quels chantiers sont en retard ce mois-ci ? »
  • « Crée une table Projets et une table Tâches reliées entre elles, avec un statut à choix. »
  • « Ajoute ces trois contacts à la table Partenaires. »
  • « Exporte la table Inscriptions en Excel. »
  • « Qui a accès au document Budget, et avec quels droits ? »

  • describe_document Obtient des informations détaillées sur un document spécifique.
  • list_tables Liste toutes les tables dans un document Grist.
  • list_columns Liste toutes les colonnes dans une table Grist.
  • list_records Liste les enregistrements dans une table Grist avec tri et limitation optionnels.

À savoir avant de brancher vos données

  • L'assistant agit avec votre clé API : il peut faire tout ce que vous pouvez faire dans Grist, y compris supprimer. Utilisez une clé d'un compte aux droits adaptés.
  • Les requêtes SQL sont limitées à la lecture.
  • En mode HTTP, le serveur n'authentifie pas ses clients : gardez-le sur 127.0.0.1 ou derrière un proxy authentifié.
  • Relancer la création d'un schéma ne crée rien en double : les tables existantes ne sont pas modifiées.
